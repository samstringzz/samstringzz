### 👋 About Me

Software Developer at **YipOnline** · based in **Lagos, Nigeria**.

I build modern, user-friendly **web and mobile** applications with a strong focus on clean UX, responsive interfaces, and scalable frontend architecture. My day-to-day stack is the **JavaScript / TypeScript** ecosystem — especially **React**, **Next.js**, and **React Native**.

I also work across the full delivery loop: API integration, auth flows, state management, and shipping apps with tools like **Firebase**, **Expo**, and modern cloud platforms.
